# Presentation contract

Live selection consumes authoritative state; it never returns or mutates gameplay. Only a newly observed same-hand SETTLED transition with valid settlement identity and newer version may start an effect; remaining Winner time does not gate it. A started effect runs 1600 ms of hero art plus a 400 ms ring exit. Normal hand/reveal/turn/action/snapshot changes cannot cancel it; resumed gameplay immediately dims the effect. Consumed events cannot replay after preference changes, resync or reconnect. Royal precedes Monster Pot, which precedes Win Streak.

Royal selection passes exactly the verified five same-suit cards from the current hand and viewer-visible board/revealed cards. Live rendering suppresses cards when proof is missing; only a labeled `demo: true` call may use synthetic spades. Monster Pot selection carries the identified winner's confirmed main/side recipient awards summed across pots, excluding return pots; its caption is `WIN {amount} CH`. Both visual sizes receive the same selection data.

The local Win Streak consumes valid, distinct newly observed settlements. Positive main/side awards are wins, split recipients each count, eligible non-winners and folded seats lose, sit-outs have no result, and a return-only result is not a win. It displays each user's actual count from ×5 onward, including after a higher-priority effect. Streak state is discarded on reconnect/resync, refresh/rejoin, identity/seat/table change, initial replay or uncertain sequence; there is no persisted or remote history.

Preview controls are constructed only for consistent deploy-preview metadata. Their callback calls a private UI presentation function with `demo: true`; no state fabrication, command, transport, payouts, live dedupe or streak mutation. Synthetic amount and selectable ×5/×6/×7/×8/×12 counts carry an explicit DEMO label. Actionable and modal layers remain readable above the FX. Natural exit removes all claim-bearing elements only when its 400 ms decorative tail begins.
