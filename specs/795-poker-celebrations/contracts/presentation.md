# Presentation contract

Live selection consumes authoritative state; it never returns or mutates gameplay. Only an observed same-hand SETTLED transition with valid settlement identity, newer version and sufficient existing reveal time may show FX. Consumed events cannot replay after preferences toggle, resync or reconnect. Royal precedes pot; streak has no live classifier.

Preview controls are constructed only for consistent deploy-preview metadata. Their callback calls a private UI presentation function with `demo: true`; no state fabrication, command, transport, payouts or dedupe update. Normal result and actionable layers remain above FX. Exiting removes all claim-bearing elements synchronously; only a faint ring remains ≤400 ms.
