No SQL schema change is required for this independent XP release. No retirement/CH/Storage/HMAC code or migrations from #1124 are included.

## Backup/recovery and breaking impact

Historical XP/levels/rankings/XP sessions are intentionally lost. New XP sessions must be created; Supabase Auth sessions remain valid. Immutable old XP endpoints fail after revocation. All live writers require V3 configuration and an epoch; missing credentials/quota failure deny XP rather than weaken rate limits or block CH settlement. No change to financial policy, eligibility or accounting. Before reset, abort with original data intact. On ambiguous/partial effect stop, preserve journal and snapshot; prefer roll-forward. Never restore whole Redis or silently reimport V2 into V3. Restoring exact XP backups requires coordinated stopped XP ingress and remaining-TTL accounting, preserving all newer/non-XP data. Backups remain restricted only for recovery; no permanent public export.
